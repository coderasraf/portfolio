# Hass Asraf Portfolio

A one-page personal portfolio website showcasing my early web development and Shopify client projects, the technologies I work with, and my work process.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white) ![Bootstrap](https://img.shields.io/badge/Bootstrap-7952B3?logo=bootstrap&logoColor=white) ![jQuery](https://img.shields.io/badge/jQuery-0769AD?logo=jquery&logoColor=white)

## Overview

My earlier portfolio site (2023), built with HTML, CSS, Bootstrap and jQuery. It introduces me as a website developer, lists the technologies I use, links to selected client projects and includes a contact form. My current site is [ashraf-siddik.com](https://ashraf-siddik.com).

## Features

- Hero section with a custom typewriter text effect and links to contact and resume
- Technologies section (Vue.js, Laravel, JavaScript, PHP, HTML5, Shopify, Bootstrap, CSS/Sass, Git, MySQL)
- "Recent projects" cards linking to live client and practice sites (Shopify stores and front-end builds)
- Three-step work process section (Plan, Development, Launch)
- Contact form handled by [Formspree](https://formspree.io/)
- Sticky header on scroll, back-to-top link and a mobile slide-out menu
- Social links (GitHub, LinkedIn, Twitter, Instagram)

## Tech Stack

- HTML5, CSS3
- Bootstrap, jQuery
- Font Awesome icons (local webfonts)
- Formspree for form submissions

## Getting Started

No build step is needed.

```bash
git clone https://github.com/coderasraf/portfolio.git
cd portfolio
# open index.html in your browser
```

## Project Structure

```text
portfolio/
├── index.html
└── assets/
    ├── css/        # Bootstrap, Font Awesome, Owl Carousel, fullPage.js, style.css
    ├── js/         # jQuery, Bootstrap, main.js, typewriter.js, opacityAnimation.js, plugins
    ├── img/        # Project thumbnails, profile and social icons
    └── webfonts/   # Font Awesome font files
```
